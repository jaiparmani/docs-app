*[ACID]: Atomicity, Consistency, Isolation, Durability — the guarantees a single-database transaction provides
*[AP]: Availability + Partition tolerance — stays answerable during a network split, at the cost of possibly-stale reads
*[API]: Application Programming Interface
*[ABR]: Adaptive Bitrate — switching video quality mid-playback as bandwidth changes
*[BGP]: Border Gateway Protocol — how independent networks announce which addresses they can reach
*[BM25]: A relevance ranking function that scores documents by term frequency weighted against term rarity
*[CAP]: The theorem that during a network partition a system must choose consistency or availability
*[CAS]: Compare-And-Swap — an atomic update that only applies if the value has not changed
*[CDC]: Change Data Capture — streaming a database's changes to downstream systems
*[CDN]: Content Delivery Network — caches content at edge locations near users
*[CI]: Continuous Integration
*[CP]: Consistency + Partition tolerance — refuses requests it cannot answer consistently during a split
*[CQRS]: Command Query Responsibility Segregation — separate write and read models
*[DLQ]: Dead Letter Queue — where messages go after exhausting retries
*[DNS]: Domain Name System — resolves names to addresses
*[FM]: Foundation Model
*[HLD]: High-Level Design — architecture and trade-offs
*[IAM]: Identity and Access Management
*[IXP]: Internet Exchange Point — a facility where independent networks interconnect directly
*[LLD]: Low-Level Design — the implementation of a mechanism
*[LLM]: Large Language Model
*[LRU]: Least Recently Used — an eviction policy
*[LFU]: Least Frequently Used — an eviction policy based on access count
*[LSM]: Log-Structured Merge tree — write-optimised storage using sorted on-disk runs
*[MCP]: Model Context Protocol — a standard interface for exposing tools to a model
*[OCP]: Open/Closed Principle — open for extension, closed for modification
*[PACELC]: Extends CAP — during a Partition choose A or C, Else choose Latency or Consistency
*[PII]: Personally Identifiable Information
*[PWA]: Progressive Web App
*[QPS]: Queries Per Second
*[RAG]: Retrieval Augmented Generation — grounding a model's answers in retrieved documents
*[ReAct]: A prompting pattern where a model alternates reasoning and acting
*[RPO]: Recovery Point Objective — how much data you can afford to lose
*[RTO]: Recovery Time Objective — how long you can afford to be down
*[SLA]: Service Level Agreement
*[SOLID]: Five object-oriented design principles: single responsibility, open/closed, Liskov substitution, interface segregation, dependency inversion
*[SRP]: Single Responsibility Principle — a class should have one reason to change
*[SSE]: Server-Sent Events — a one-directional server-to-client stream over HTTP
*[TLS]: Transport Layer Security — the encryption behind HTTPS
*[TTL]: Time To Live — how long a cached or leased value stays valid
*[WAL]: Write-Ahead Log — record the intent before mutating the data
*[2PC]: Two-Phase Commit — a blocking protocol for atomic commits across services
