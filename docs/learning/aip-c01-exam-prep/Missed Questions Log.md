# Missed Questions Log

The highest-leverage note in this folder — it's the only one that gets more valuable every time you use it. After every timed mock, add a row for every question you got wrong (or guessed right without being sure). Review this whole table before your next mock, and again the night before the real exam.

## How to fill this in
1. Question number + source (which mock, e.g. "Mock 1 Q13")
2. What you answered vs. the correct answer
3. The one-sentence reason you got it wrong (wrong service, missed a trap, didn't know the fact, misread the scenario)
4. A link to the deep note that actually covers this
5. Mark it `[ ]` unresolved until you can explain the correct answer cold without looking, then `[x]`

## Patterns to watch for as this fills in
Once you have 10+ entries, look for clustering:
- **Same domain repeatedly?** → that domain needs a full re-read, not just this log.
- **Same trap type repeatedly** (e.g. always picking the biggest model, always missing the data-residency conflict)? → that's a specific exam instinct to drill, add it to [Rapid Recall Cram Sheet](Rapid Recall Cram Sheet.md)'s "cross-cutting exam instincts" section if it's not already there.
- **Same service confused with another** (e.g. Comprehend vs. Macie, Lambda vs. ECS for MCP)? → add a explicit row to [Service Selection Drill](Service Selection Drill.md) contrasting the two directly.
