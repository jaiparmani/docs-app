# 07 — Curiosity Gaps: Turning a Task Into a Mystery

<small>3 min read</small>

## Core idea
Curiosity is a distinct motivational force from reward-seeking — it's driven not by an anticipated payoff but by an awareness of a gap between what you currently know and what you could know, a gap the mind finds mildly uncomfortable and wants closed. Unlike reward-based motivation, which tends to fade with repetition (the tenth rep of anything is less exciting than the first), curiosity can be manufactured freshly at almost any point by deliberately creating or highlighting an unresolved question, which makes it an unusually renewable fuel source for tasks that have otherwise gone stale.

## Why it matters
Most motivational tactics eventually run into diminishing returns: rewards need to grow to keep having the same effect, and the novelty of a new goal fades the more familiar it becomes. Curiosity doesn't obey quite the same decay curve, because it isn't about the object of the task at all — it's about whatever specific unresolved question is currently attached to it. That means a task that's become routine and unmotivating can often be reinvigorated not by adding a bigger reward, but by finding or inventing a genuine unknown inside it — what will the data actually show, how will this particular version of the problem resolve — that you don't yet have the answer to.

## Example from the book
Fishbach draws on the information-gap account of curiosity most associated with the psychologist George Loewenstein, which frames curiosity as arising specifically from an awareness of a gap in one's own knowledge, and connects it to her own lab's work on how introducing small, resolvable unknowns into an otherwise routine task changes engagement with it. In studies of this kind, participants working through a repetitive or tedious task persist longer and report more interest when the task is restructured to include an element whose outcome they don't yet know — an unresolved trivia question, an uncertain result they'll only learn by continuing — compared with an otherwise identical task where the outcome is already known or where completion carries no informational payoff at all. Knowing the ending in advance, even a good one, consistently produces less sustained engagement than not knowing it.

## Practical application
For a task or goal that's become dull through repetition, look for a genuine unknown you could attach to it rather than reaching for a bigger reward. That might mean tracking a metric whose trajectory you're actually uncertain about instead of one you already know the answer to, framing a work problem as "I wonder if this approach will actually work" instead of executing a known procedure, or introducing variation specifically so the outcome isn't predictable in advance. The key constraint is that the curiosity has to be real — a manufactured question you already know the answer to doesn't produce the same pull as a genuinely open one.

## Something to sit with
> [!question]- A question to think about
> Is there a task you've made boring by making it too predictable — and is there a real unknown you could reintroduce into it that you don't already know the answer to?
