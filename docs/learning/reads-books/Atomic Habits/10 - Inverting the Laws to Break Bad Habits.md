# 10 — Inverting the Laws to Break Bad Habits

<small>2 min read</small>

## Core idea
Everything in chunks 05-08 was about building good habits by making them obvious, attractive, easy, and satisfying. Clear's approach to breaking bad habits isn't a separate framework — it's the same four laws run in reverse: make the cue **invisible**, make the habit **unattractive**, make the response **difficult**, and make the outcome **unsatisfying**. Since a bad habit still runs on the same four-stage loop as a good one, the same four levers that build a habit can be used to dismantle one.

## Why it matters
This collapses what looks like two separate problems (build good habits / quit bad ones) into one skill applied in both directions, which means everything already learned in chunks 05-08 is directly reusable rather than requiring new theory. It also reframes "quitting" a bad habit away from pure willpower-based resistance — instead of white-knuckling through a craving every time it appears, the goal is to engineer the loop itself so the craving has less opportunity to trigger in the first place (invisible cue) and less reward waiting for it if it does (unsatisfying outcome).

## Example from the book
Clear's own example is a smartphone habit: making the cue invisible by leaving the phone in another room while working, making it unattractive by consciously reframing the craving ("I don't need this notification, it's designed to be addictive, not actually important"), making it difficult by adding friction — logging out of apps so a password is required every time, or deleting the app outright so it takes real effort to reinstall — and making it unsatisfying by enlisting a friend or partner to know about the goal, so any lapse carries a small social cost. None of these four individually eliminates the habit; together, each stage of the loop gets harder to complete.

## Practical application
Take one habit you're trying to quit and write all four inversions concretely, the way you'd write the four laws for a habit you're building: What specifically would make the cue invisible in my actual environment? What would make the craving genuinely less attractive, not just something I'm resisting? What friction can I add to the response? What would make completing it actually unsatisfying rather than just guilt-inducing afterward? A habit you're only resisting through willpower is missing at least one of these four.

## Something to sit with
> [!question]- A question to think about
> For a habit you've tried to quit through willpower alone, which of the four inversions have you never actually applied — and what would it look like to apply the one you're missing today?
