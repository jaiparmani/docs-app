Core Concept - 
# 110 << 3 → 110000

# 110000 | 101 → 110101

One bit of current appending character increases when the number is divisible by 2
```
MODULO = 10**9 + 7
class Solution:
    def concatenatedBinary(self, n: int) -> int:
        numBits = 0
        isDivBy2 = lambda i: i & (i - 1) == 0
        ans = 0
        for i in range(1, n + 1):
            if(isDivBy2(i)):
                numBits += 1
            ans = ans << numBits
            ans = ans | i
            ans %= MODULO
            # 110 << 3   → 110000
# 110000 | 101 → 110101

        return ans    
```
