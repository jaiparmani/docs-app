Try using this mental checklist every time:

1. Features

- What should the system do?

3. Scale

- How much traffic/data?

5. Reliability

- Can we lose data? Retry? Duplicates?

7. Latency

- Synchronous or asynchronous?

9. Constraints

- Any special business rules?

If you consistently cover those five areas in the first 2–3 minutes, you’ll come across as someone who systematically explores the problem rather than remembering a checklist.
